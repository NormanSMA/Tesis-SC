# Registro de cambios publicado

`Registro de cambios por módulo.docx` es la copia versionada del registro revisado, para compartir el avance por GitHub. Incluye las entregas hasta GEN-08; la copia se sincroniza con el documento maestro de trabajo antes de publicar.

En el entorno local documentado por `docs/coordinacion/README.md`, el maestro permanece en `../Registro de cambios por módulo.docx` desde la raíz `Tesis-SC/`. Esta copia no sustituye el respaldo previo requerido antes de editar el maestro. Al clonar el proyecto, la copia publicada permite recuperar el registro sin depender del equipo de origen.

Las evidencias visuales de esta entrega se conservan en `docs/capturas/`. El registro operativo vivo, credenciales, bases de datos y respaldos permanecen locales y no forman parte de la publicación.

# Íconos animados

Componentes copiados de [lucide-animated](https://lucide-animated.com/) (licencia MIT, autor pqoqubbw), basados en Lucide y animados con Motion.
No se modifican: se excluyen de ESLint para poder reemplazarlos por una versión nueva.

Cada ícono acepta `ref` con `startAnimation()` y `stopAnimation()`. El menú los dispara al pasar el mouse, al enfocar y al abrir la sección activa, salvo si el usuario pide reducir el movimiento.
Para agregar otro: `curl https://lucide-animated.com/r/<nombre>.json` y guardar el campo `files[0].content`.
